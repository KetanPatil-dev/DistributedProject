========================================================================
  FORMULA SUMMARY (Cao 2016, with alpha+ = alpha- = 0.5*BW)
========================================================================

  Notation:
    C_i    = tx time of S_i = size*8/link_rate,  T_i = period of S_i
    alpha+ = idleSlope = 0.5*BW  (credit rises while queue waits)
    alpha- = sendSlope = 0.5*BW  (credit falls while transmitting)

  AVB-A (Cao 2016 WFCS Thm 4 — iterative busy-window):
    R_A(Si) = C_i + LPI + sum_{j!=i,A} ceil(R/T_j) * C_j * (1+alpha-/alpha+)
    LPI = max_{B,BE} C_j * (1+alpha+/alpha-)  =  2*C_L_max
    (LPI: lower frame transmitting -> A credit recovers -> eligible interval delayed)

  AVB-B (Cao 2016 RTNS Thm 3 — iterative busy-window):
    R_B(Si) = C_i + MPI + sum_{j!=i,B} ceil(R/T_j) * C_j * (1+alpha-/alpha+)
    MPI = C_BE_max*(1+alpha+/alpha-) + C_A_max  =  2*C_BE_max + C_A_max

  BE (non-preemptive iterative RTA, A+B as strict higher priority):
    R_BE(Si) = C_i + B_block + credit_block + sum_{A,B} ceil(R/T_j)*C_j
    B_block      = max C_j over ALL streams  (any frame may be mid-tx)
    credit_block = (C_A_max + C_B_max)*(alpha-/alpha+)  [CBS debt recovery]

  SP — Strict Priority, no CBS (non-preemptive FP-RTA, FIFO within priority):
    R_SP(Si) = C_i + B_block
               + sum_{prio(j)<prio(i)} ceil(R/T_j)*C_j
               + sum_{prio(j)=prio(i),j!=i} ceil(R/T_j)*C_j
    B_block = max C_j over ALL streams.  Priority: A(0) > B(1) > BE(2)

  Multi-hop (H identical hops, same-direction streams, line topology):
      WCD_total(Si) = H * WCRT_per_hop(Si)
